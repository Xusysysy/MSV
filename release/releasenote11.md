# MSV 乐谱查看器 v2.1.3

## 新增

- **更新包下载完成后自动调起安装**：下载成功即弹系统安装器（未授予"安装未知应用"权限时引导授权页）
- **查看更新日志**：检查更新发现新版本后，设置面板可展开查看两平台 Release 的完整更新日志
- 下载更新包期间"检查更新"按钮置灰禁用（显示"下载中…"）

## 修复

- **修复已渲染页面瞬间消失又显示的问题**：渲染请求改为按页面 URI 固化（remember），不再因其他页渲染完成触发重组而重启请求；页面分层升级换缓存时先用 Coil 预热内存缓存再切换，消除加载空白帧
- **翻页触发瞬间页码即更新为目标页**：任意翻页方式（点击/拖拽/面部翻页）在触发时立即推进页码（页码显示、渲染、预加载全部以目标页为准），不再等动画结束；翻页动画只负责视觉过渡
- **当前页未渲染时渲染优先级立即重排**：快速翻页模式当前页同步优先渲染、其余页并行；翻页触发即取消旧的预加载任务并按新当前页重算优先级

## 技术变更

- Stage 新增 flipDir 状态区分翻页动画期与拖拽期的页面定位；doFlip 页码推进从动画完成回调移至触发点
- UpdateInfo 新增 fullNotes 字段（完整 release body）
- versionCode=11, versionName=2.1.3
