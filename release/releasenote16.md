# MSV 乐谱查看器 v2.1.8

## 新增

- **更新包下载断点续传**：下载中断（杀进程/断网/取消）后重新下载自动从断点继续（Range 请求）；本地已与远端等长时（416）视为下载完成
- **已下载未安装，检测直接进入安装阶段**：检查更新时自动比对本地更新包与远端大小，一致则跳过下载直接调起安装
- **书签编辑功能**：长按书签菜单"重命名"升级为"编辑"，与新建书签一致——可改名称（≤50 字）与颜色

## 修复/优化

- **书签视觉全面打磨**：
  - 透明度降低（更通透的 0.55）
  - 全部书签右端对齐，右端在文字结束后延长一段并置于缩略图面板**下一图层**（经典书签插页效果）
  - 书签与文字加大（文字 13sp 单行不换行），书签条之间留出间隙
  - 修复滚动到底部时最后一个书签显示不全的问题（底部留白）

## 技术变更

- UpdateRepository.downloadApk 重写：Range 续传 + 416 完整判定 + 失败保留断点；新增 remoteApkSize/isDownloaded
- 移除下载失败即删文件的逻辑（改为保留断点）
- ThumbnailPanel 根布局改为 Box 图层结构（书签栏在缩略图面板下层），书签条 requiredWidthIn + offset 实现"右端对齐 + 尾部延伸"
- RenameBookmark 事件增加 color 字段（编辑可改色）
- versionCode=16, versionName=2.1.8
