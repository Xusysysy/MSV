# MSV 乐谱查看器 v2.3.9

## 修复

- **搜索结果页"返回"按钮失效**：结果网格点返回无反应的 bug 已修复（现正确回到搜索页；从浏览页搜索进入的结果页则返回浏览页）
- **状态行把内容挤出弹窗**：搜索弹窗出现"搜索中…"等状态文字时不再把底部内容推出弹窗外（高度动态计入）
- **官方页下载按钮"消失"**：多数情况是页面尚未加载完成——网页加载中现在显示明确的"加载中…"覆盖层（转圈+文字），完成后自动消失；页面加载完成前不再误以为按钮丢失。若加载完成后下载入口仍缺失，请反馈截图

## 优化

- **浏览页顶部搜索框收起式设计**：默认收起为一个小胶囊（不再占用大块空间），点击后展开为输入行（带过渡动画并自动聚焦），提交搜索后自动收起
- **搜索框样式统一**：搜索页与浏览页搜索框统一为矮高度（50dp）+ 大圆角（20dp），与弹窗整体风格协调，消除割裂感
