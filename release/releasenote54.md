# MSV 乐谱查看器 v2.5.1

## 应用图标调整

- **音符明显变大**：占图标面积从约 28×40 提升到约 59×46 单位，48dp 尺寸下更有分量、更容易一眼认出
- **改为「上行双音符 + 倾斜符杠」**：从单枚四分音符（较平淡）换成被符杠连在一起的两枚八分音符，两音一低一高、符杠向上倾斜，带出「翻页向前」的动感，比通用音乐图标更有记忆点
- **双色更有辨识度**：符杆与符杠为前景白、两枚符头为应用强调蓝，深浅对比比单色更醒目
- 依旧为矢量自适应图标（含单色主题图标层），已用脚本按圆形遮罩实测内容全部落在安全区内，各遮罩下不裁切

> 功能无变化，仅图标视觉调整。
