# MSV 乐谱查看器 v2.3.7

## 优化

- **IMSLP 官方页加载提速**：内嵌浏览不再加载广告与统计类第三方资源（gtag/Clarity/各大广告网络等，占页面加载与流量的主要部分），页面打开明显更快、更省流量；站点功能与人机验证组件不受影响
- **页面加载进度条**：浏览官方页时顶部实时显示加载进度，加载过程可感知
- **搜索提速**：作品与作曲家两组搜索请求由串行改为并行，出结果等待约减半
- **观感修复**：点击乐谱后应用内立即开始下载，同时自动隐藏站点弹出的"15 秒等待"倒计时弹窗（实际下载本就无需等待，此前弹窗会一直挂在页面上造成困惑）
