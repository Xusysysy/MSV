# MSV 乐谱查看器 v2.4.9

## 修复：IMSLP 乐曲详情页的「预览」恢复

- **预览失效的原因不是应用删掉了功能，而是 IMSLP 近期改版**：站点不再使用旧的文件按钮标识，导致应用内预览脚本取不到乐谱文件编号，于是静默跳过（表现就是"预览没了"）。
- **文件编号改为读取稳定的条目标识**（改版后的新位置），旧的读取方式保留为兼容分支，两种页面结构都能取到编号。

## 改进：预览入口改为应用自带

- 每个乐谱条目旁新增一个 **「📖 预览」按钮**，点击即在该条目下展开可翻页预览。
- 该入口**不再依赖 IMSLP 自身的 View 按钮，也不依赖其官方预览组件是否可用**（官方组件在部分网络下不可达）——站点后续再改版也不会让预览消失。
- 点击 IMSLP 自带的 View 仍然兼容：官方预览组件可用时优先使用官方组件，不可用时才接管。

> 预览图片仍来自公开的乐谱预览图片接口，不在本地存储任何乐谱内容。
