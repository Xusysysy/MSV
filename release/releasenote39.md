# MSV 乐谱查看器 v2.3.6

## 重构：IMSLP 下载链路全面改为官方页浏览

- **搜索保留应用内**：作曲家与作品的搜索仍由应用直连 MediaWiki API 完成
- **点击结果直达官方页**：点击作曲家/作品后，内嵌 WebView 直接打开 IMSLP 官方页面浏览（真实浏览器上下文，人机验证通过率最大化）
- **应用内下载**：在官方页点击乐谱 PDF 链接时自动转为应用内下载（进度条实时显示），完成后自动导入谱架并打开
- **跳过免责声明页**：预置已同意 cookie，不再弹出免责确认
- **跳过 12 秒等待**：等待页的真实下载地址直接从页面中解析并立即下载，无需倒计时
- **人工验证自动衔接**：若命中 Bot Check 门禁，验证页在 WebView 内呈现，完成 "Start Verification" 后自动继续下载
- 移除旧的 API 详情解析与独立验证步骤（曲目信息以官方页面展示为准）
