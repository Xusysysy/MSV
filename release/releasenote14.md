# MSV 乐谱查看器 v2.1.6

## 修复

- **删除乐谱增加二次确认**：长按菜单选择"删除"后弹出确认对话框（"确定删除…此操作不可恢复"），确认后才执行删除
- **弹窗 UI 与应用设计语言统一**：谱架长按菜单与排序下拉菜单使用面板同款深浅色背景、圆角与主题文字色，不再使用系统默认白色样式
- **修复谱架排序选择器不工作的问题**：排序在渲染层兜底执行（选择器切换必然改变可见顺序），ShelfFile 携带 lastModified 供日期排序；切换时给出"已按名称/日期排序"反馈
- **修复竖屏面部识别关键点线条明显错位的问题**：送检位图（已旋转/镜像）尺寸记入 FaceState，叠加线条按预览 FIT_CENTER 映射计算缩放与留白，与画面精确对齐
- **修复横屏翻页短暂闪烁的问题**：单页渲染图层化——升级换缓存时旧图垫底显示、新图解码完成后覆盖，切换零空窗

## 新增

- **应用内下载更新包**：不再使用系统下载器，设置面板实时显示下载进度条与百分比（支持取消）；下载完成后自动调起安装，设置面板同时提供"立即安装"按钮

## 技术变更

- UpdateRepository 移除 DownloadManager 链路，新增 downloadApk 流式下载（协作式取消）
- ViewerState 新增 downloadProgress 字段；移除 ACTION_DOWNLOAD_COMPLETE 接收器
- versionCode=14, versionName=2.1.6
