# MSV 乐谱查看器 v2.5.3

## 应用图标：简化为纯黑白

- **纯黑白**：底色改为纯黑 `#000000`，音符全部改为纯白，不再有强调蓝与暗蓝底
- **去掉五线谱**：背景只保留纯黑，图形元素从「谱线 + 符杠 + 符杆 + 符头」精简为「符杠 + 符杆 + 符头」，明显更简洁
- **整体缩小约 10%**：占幅由 61×47 收到 54×42、符杆由 10 收到 9，放到手机上不再显得过大
- **保留辨识度**：仍用「上行双音符 + 微弧符杠」而非通用的单枚 ♪——单音符几乎每个音乐类应用都在用；微弧符杠（二次曲线）取代生硬直线，是这一版的识别特征

> 各角点到圆心 ≤30.4，远小于自适应图标安全半径 36，各形状遮罩下都不会裁切。功能无变化。
