# MSV 乐谱查看器 v2.1.13

## 修复

- **修复设置页卡在"检查中…"的问题**：冷启动静默检查在"清单显示已是最新"时未重置检查状态，导致设置页永远显示"检查中…"；现已正确回落到空闲态

## 变更

- **书签改为完全不透明**：背景不再半透明，文字统一改为黑色，移除黑描边叠层与阴影（单层渲染更清晰）
- **下载可暂停**：设置页"下载中…"按钮现在可点击——点击暂停下载；暂停后按钮变"继续下载"，点击后按断点续传恢复下载

## 新增

- **开源许可**：设置页底部新增"开源许可"入口，点击弹窗列出本应用使用的开源项目（Kotlin / Jetpack Compose / AndroidX / Coil / DataStore / CameraX / MediaPipe / pdfbox-android 等）及其许可证

## 技术变更

- UpdateStatus 新增 Paused；SettingsPanel 主按钮随状态切换"检查更新/暂停下载/继续下载"
- versionCode=21, versionName=2.1.13
