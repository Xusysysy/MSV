# MSV 乐谱查看器 v2.2.3

## 修复

- **任意放大状态双击恢复正常模式**：之前仅 ≥2x 双击才恢复（<2x 会继续放大）——现在任何放大状态（>1x）双击都恢复到 1x 并退出缩放模式；仅 1x 时双击才步进放大到 2x

## 新增

- **未渲染页占位图**：页面尚未渲染完成时显示内置占位图（乐谱未加载/加载中），不再露出背景
  - 启动时解码一次并常驻内存（全局单实例，任意页数复用，防缓存爆炸）
  - 占位图→乐谱：真实页面渲染完成后 180ms 短暂渐变过渡，无跳变
  - 深色主题下占位图随页面一起反色

## 技术变更

- 新增 res/drawable-nodpi/page_placeholder.jpg + PagePlaceholderCache 单例（VM init 预热）+ PageWithPlaceholder（占位底层+淡入）
- Stage 双击阈值：<2f → >1.01f（恢复判定）
